# API de cursos

Api para gerenciamentos de professores e cursos

## Tecnologia
- JavaScript
- mysql
- node JS
- express

## Endpoint
- `POST /professores` - criar professores
- `GET /professores` - Listar professores
- `POST /cursos` - criar um curso
- `GET /cursos` -Lista cursos
- `DELETE /cursos/:id` -Deleta um curso por id
